# Phase 1 기준선 측정 결과

측정일: 2026-10-18 · 환경: CPU only (onnxruntime CPU), Python 3.12 venv

## 테스트 설정

| 항목 | 값 |
|---|---|
| 검출/인식 | InsightFace `buffalo_l` (SCRFD + ArcFace ResNet50@WebFace600K) |
| 검출 입력 크기 | 640×640 |
| 영상 | 60프레임, 1200×630, 10fps (전반 30프레임: 미등록 6명 / 후반 30프레임: 등록인물 1명) |
| 인물 DB | 5명 (repo `data/test_images` 기반, obama 제외 — 검출 불가) |
| 인식 임계값 | 코사인 유사도 0.4 |
| 트래커 | ByteTrack (track_thresh=0.5, max_time_lost=30) |

## 결과

| 지표 | 트래킹 사용 | 트래킹 미사용 |
|---|---|---|
| 처리 시간 (60프레임) | 123.7s | 120.0s |
| 평균 FPS | 0.5 | 0.5 |
| 인식 호출 횟수 | **21회** | **210회** |
| 등록인물 인식 | 정상 (후반부 초록 박스, 모자이크 제외) | 정상 |
| 미등록 모자이크 | 전 프레임 적용 | 전 프레임 적용 |

## 해석

1. **인식 호출 10배 감소**: 트래킹 도입으로 신규 트랙에 대해서만 인식을 수행하므로, 동일 인물의 반복 인식이 제거됨. GPU 환경에서는 검출 병목이 해소되어 이 차이가 FPS에 직접 반영될 것.
2. **CPU FPS 병목은 검출**: SCRFD 640px CPU 추론이 프레임당 ~2초로 전체 시간의 대부분을 차지. 실시간 처리는 GPU(CUDAExecutionProvider) 필수.
3. **정확도**: 등록인물 1.00 유사도로 정확히 식별, 미등록 6명 전원 모자이크 (유사도 0.06~0.15).
